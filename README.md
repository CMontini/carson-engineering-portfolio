# Carson Montini — Mechanical Engineering Portfolio

Rebuilt as a clean React + Vite + TypeScript project.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Current structure

- Home — concise engineering positioning and selected work
- Engineering Archive — Charger 4 and Charger 5
- Charger 4 — segment design/manufacturing, busbars, electrical calculations
- Charger 5 — independent PDU design/manufacturing, accumulator and busbar research
- Personal Projects — staged placeholder for Mission and Acura expansion
- source-material/c5-pdu — STL and DXF files supplied for the PDU work

## Before publishing

Update the email link in `src/components/SiteShell.tsx` from `montini.carson@gmail.com` to the desired contact email.
